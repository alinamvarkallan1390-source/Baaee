# 🤖 Life Simulator AI — ربات بازی بله (Baaee)

**یک بازی متنیِ شبیه‌ساز زندگی، کامل و فارسی، در قالب یک ربات برای پیام‌رسان «بله».**
کاربر یک کاراکتر می‌سازد و با منوهای شیشه‌ای، زندگیِ دومش را می‌سازد: شغل، پول، بانک، خانه، بورس، جنگ، هک، اتحاد، خانواده، پت، شهر و صدها فعالیت دیگر.

```
🆔 نسخه‌ی فایل اصلی: main.py  |  v1.1.0  |  بیلد: v110-god-2026-09-25
🐍 پایتون ۳.۹+ (پیشنهاد: ۳.۱۱)   📦 تنها وابستگی: requests
🗄 دیتابیس: SQLite تک‌فایل   📡 روش دریافت پیام: Long Polling
👨‍💻 توسعه: تیم XR
```

## 🎯 معرفی

ربات از یک **فایل پایتونِ تک‌مونولیت** (`main.py` — حدود ۱۵٬۰۰۰ خط) تشکیل شده که:

- با **Bale Bot API** (سازگار با Telegram Bot API روی `tapi.bale.ai`) با **لانگ‌پولینگ** کار می‌کند،
- داده‌ها را در **SQLite** (حالت WAL، با یک `RLock` برای ایمنی بین تردها) نگه می‌دارد،
- همه‌چیز را با **کیبورد شیشه‌ای (Reply Keyboard)** برای منوها و **دکمه‌های اینلاین** برای اکشن‌ها ارائه می‌دهد،
- و یک **سرور HTTP سبک** روی پورت `PORT` برای health-check باز می‌کند تا روی هاست‌های رایگان خاموش نشود.

### 💼 کار و شغل

- **مصاحبه‌ی استخدامی ۲سؤالی** برای مشاغل حرفه‌ای (بانک ۸ سؤال)

- پیمان کاری: پنجمین شیفت هر روز = پاداش ۳×
- خطر اخراج اگر شادی زیر ۲۰ برود
- کارگری روزمزد، تاکسی با ماشین شخصی (۳/روز)، ماهیگیری (۳ قلاب/روز)، اجرای خیابانی، فروش تابلو، تولید محتوا

### 💰 اقتصاد و بازار
- **فروشگاه** (۹ آیتم)، 🎓 تحصیل (۳ مدرک)، 📛 لقب‌ها (۴ مورد)، 💱 صرافی سکه
- **بورس با ۲۶ نماد** (طلا، دلار، بیت‌کوین، نفت، زعفران، …) با رندوم‌واک، کف/سقف ضدتقلب و کارمزد ۲٪

- **ترکیب/ذوب آیتم**، پیشه‌فروشی (۷۰٪ قیمت)، ⚡ فلش‌سیل ۳۰٪، معامله طلایی روزانه
- **امپراتوری تجاری**: ۸ نوع شرکت، ۴ نقش کارمند، ارتقا تا سطح ۵، عرضه/خرید سهام، وام تجاری، تبلیغات

### 🏦 بانک

### ⚔️ جنگ و هک

- **جنگ اتحاد**، تسلط بر ۶ منطقه‌ی شهر، مأموریت هفتگی اتحاد
- 🐉 باس روزانه، ⚔️ آرنا هفتگی (۴ رده)، 🧗 برج قهرمانان، 🗺️ ماجراجویی (کاوش)

```
[10] حلقه‌ی اجرای اصلی        (۱۴۷۶۳–۱۵۰۰۹)
```

### جریان پردازش هر پیام

```
main()
 ├─ start_keepalive()          ThreadingHTTPServer روی 0.0.0.0:$PORT → فقط /health
 ├─ Database(DB_PATH)          SQLite + WAL + RLock + مهاجرت خودکار اسکیما
 ├─ ensure_v109()              مهاجرت ستون‌های نسخه ۱.۰.۹
 ├─ start_backup_loop()        اولین بکاپ ۱۵ دقیقه بعد، سپس هر ۶ ساعت
 ├─ BaleAPI(BOT_TOKEN)         getMe برای تست اتصال
 └─ while True:
      api.poll()               getUpdates با timeout=25 و limit=100
        └─ handle_update(u)
             ├─ world_engine()        رویداد جهانی (تنبل، هر ۴ ساعت)
             ├─ reminders_tick()      ارسال یادآورهای سررسیده
             ├─ handle_message(msg)   متن → تشخیص دستور/منو/فرم
             └─ handle_callback(cb)   کلیک اینلاین → زنجیره‌ی if/elif روی پیشوند
```

### نکات طراحی قابل‌توجه

| مکانیزم | توضیح |
|---|---|
| **خود-ترمیمی اسکیما** (`_try_heal`) | اگر کوئری با `no such column/table` شکست خورد، همان لحظه `_init_schema()` و `_seed()` اجرا و کوئری تکرار می‌شود — برای سیوها و بکاپ‌های قدیمی |
| **انتخاب مسیر دیتابیس** (`_pick_db_path`) | مسیر را با **تست واقعی نوشتن** روی دیسک انتخاب می‌کند؛ اگر هاست فقط‌خواندنی بود به پوشه‌ی موقت سقوط می‌کند |
| **بکاپ خودکار** | هر ۶ ساعت فایل دیتابیس (پس از `wal_checkpoint(TRUNCATE)`) برای ادمین فرستاده می‌شود |
| **بازیابی از بکاپ** | ادمین فایل `.db` را در چت می‌فرستد → `restore_db_from_document` جایگزین می‌کند (قبلش از وضعیت فعلی بکاپ می‌گیرد) |
| **کد بازیابی یک‌بارمصرف** | ادمین می‌تواند کاربر را ریست کند و یک کد تولید کند تا دارایی‌هایش را به حساب جدید منتقل کند |
| **جوین اجباری** | بررسی عضویت در کانال با کش ۹۰ ثانیه‌ای؛ در صورت خطای API عبور موقت (بازی قفل نمی‌شود) |
| **ضد اسپم/تقلب** | محدودیت ۳۰ اکشن در دقیقه + کول‌داون اختصاصی برای هر عمل + `is_bot` و چت غیرخصوصی را نادیده می‌گیرد |
| **فیلتر نام** | نرمال‌سازی عربی/نیم‌فاصله/اعراب + لیست کلمات ممنوعه + لیست استثنا (مثل «تایکون») |
| **هوش در ترد جداگانه** | `_ai_background` پاسخ را در Thread می‌سازد تا حلقه‌ی اصلی قفل نشود |
| **برندینگ خودکار** | پانوشتِ `👨‍💻 توسعه: XR Team | نسخه` به انتهای هر پیام (با رعایت سقف ۴۰۹۶ کاراکتر) |

```python
BOT_TOKEN    = "توکن-ربات-بله"
```

سپس فقط دکمه‌ی Run ▶ را بزنید. مسیر دیتابیس به‌طور خودکار کنار فایل ساخته می‌شود.

## 🧠 هوش مصنوعی (در ۱.۱.۰ کاملاً بازی‌محور شد)

دستیار هوش (که در ۱.۱.۰ کاملاً بازی‌محور شده) با سه لایه‌ی پشت‌هم (هیچ‌وقت `None` برنمی‌گرداند):

```
۱) OpenRouter  → تلاش روی چند مدل پشت‌سرهم (در صورت ۴۰۱/۴۰۲/۴۰۳ متوقف می‌شود)
۲) Pollinations (text.pollinations.ai)  → فال‌بک رایگان بدون نیاز به توکن
۳) پاسخ آفلاینِ هوشمند (_ai_offline_answer) → پاسخ‌های آماده بر اساس کلیدواژه
```

| تنظیم | مقدار |
|---|---|
| مدل پیش‌فرض | `openrouter/free` → در عمل `meta-llama/llama-3.2-3b-instruct:free` |
| مدل‌های پشتیبان | `gemma-2-9b`, `qwen-2-7b`, `llama-3.1-8b`, `gpt-4o-mini` |
| بودجه‌ی کل زمان | ۳۰ ثانیه (`AI_TOTAL_BUDGET`) |
| تایم‌اوت هر مدل | ۱۲ ثانیه |
| سقف روزانه | ۲۰ چت + ۸ داستان برای هر کاربر |
| هزینه برای کاربر | رایگان (`AI_CHAT_COST = 0`) |
| کول‌داون | ۱۵ ثانیه |

**قابلیت‌ها:** چت آزاد با آگاهی از وضعیت کاربر (نام، لول، پول، شغل)، ۶ سؤال سریع (پول/عشق/بورس/هک/لول‌آپ/خانه)، داستان‌ساز شخصی‌سازی‌شده.
ادمین می‌تواند از پنل «🤖 تنظیمات هوش» کلید، مدل و پرامپت سیستم را تغییر دهد و اتصال را تست کند.

- هرگز فایل `.env` یا `life_simulator.db` را کامیت نکنید (دیتابیس حاوی اطلاعات کاربران است).
- بکاپ‌هایی که ربات برای ادمین می‌فرستد، کل دیتابیس هستند — آن‌ها را در جای امن نگه دارید.
- برای اجرا در production، دیتابیس را روی یک Volume دائمی (مثل `fly.toml`) نگه دارید.

|---|---|
| `❌ توکن ربات تنظیم نشده!` | `BALE_BOT_TOKEN` خالی است یا با `PUT_YOUR` شروع می‌شود |

| `⚠️ Conflict: یه نسخه دیگر … دارد کار می‌کند` | دو نمونه از ربات همزمان اجرا شده‌اند؛ یکی را متوقف کنید (کد ۱۰ ثانیه صبر می‌کند و ادامه می‌دهد) |
| دکمه‌ای کار نمی‌کند | معمولاً ستونی از دیتابیس جا مانده — مکانیزم خود-ترمیمی در اولین استفاده اجرا می‌شود؛ در صورت تکرار، ربات را یک‌بار ری‌استارت کنید |
| جوین اجباری همه را بلاک کرده | ربات باید در کانال **ادمین** باشد؛ در غیر این صورت چک عضویت با خطا مواجه و به‌طور موقت عبور می‌دهد |
| پیام همگانی کند است | ارسال به‌صورت همزمان و بچ‌بندی‌شده انجام می‌شود و حلقه را برای مدتی درگیر می‌کند |
| دیتابیس بعد از ری‌استارت پاک شد | هاست فایل‌سیستم موقت دارد؛ `LIFE_SIM_DB` را روی Volume تنظیم کنید و از بکاپ خودکار استفاده کنید |
| `no such column: …` | فقط یک هشدار است؛ اسکیما خودکار ترمیم و کوئری تکرار می‌شود |

لاگ‌ها با قالب `زمان | سطح | پیام` در خروجی استاندارد چاپ می‌شوند.

## ⚠️ محدودیت‌های شناخته‌شده و بدهی فنی

- **یک فایل ۱۵ هزار خطی**: نگه‌داری و تستِ آن دشوار است؛ تقسیم به ماژول‌ها (core/db/game/admin) توصیه می‌شود.
- **`handle_callback` حدود ۱۱۰۰ خط با حدود ۳۲۰ شاخه‌ی `startswith`**: جایگزینی با یک جدولِ مسیریابی، ریسکِ «دکمه کار نمی‌کند» را کم می‌کند.
- **ارسال همگانی همزمان است** و می‌تواند برای دقایقی ربات را برای همه کند کند؛ انتقال به صف/ترد پس‌زمینه بهتر است.
- **عملیات مالی تراکنش اتمیک ندارند** (هر `execute` جداگانه commit می‌شود)؛ استفاده از `BEGIN IMMEDIATE` یا `UPDATE … SET money = money + ?` توصیه می‌شود.
- **`world_engine` و `reminders_tick` تنبل هستند** و فقط هنگام دریافت آپدیت اجرا می‌شوند؛ بدون ترافیک، رویدادها آتش نمی‌زنند.
- **تکثیر با نسخه‌ی روبیکا**: `main2.py` در واقع یک انشعاب از v1.0.5 است و حدود ۱۹۳ تابعِ نسخه‌ی بله (از جمله کل ماژول هوش مصنوعی، حراجی، بازار سیاه و آرنا) را ندارد؛ شباهت خط‌به‌خطِ دو فایل حدود ۷۶٪ است و هر رفعِ باگ باید دو بار اعمال شود.
- **نسخه‌گذاری ناهماهنگ**: `CHANGELOG_1.0.7.md` قدیمی‌تر از کد است (کد ۱.۱.۰) و برای ۱.۰.۸/۱.۰.۹/۱.۱.۰ یادداشتِ انتشار وجود ندارد.
- **بدون تست و CI**.
